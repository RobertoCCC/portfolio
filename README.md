# Portfolio

Single-page landing showcasing five software demos built for Portuguese SMBs.

**Live:** _coming soon (Vercel deploy in progress)_

Static HTML + CSS, no JavaScript framework, no build step. Deploys instantly to any static host.

## What's listed

| Demo | What it solves | Live |
| --- | --- | --- |
| Consultório | Practice management for clinics, law firms, accountancies | [consultorio-theta.vercel.app](https://consultorio-theta.vercel.app) |
| Loja PT | E-commerce storefront + admin for a local Portuguese shop | [loja-pt-psi.vercel.app](https://loja-pt-psi.vercel.app) |
| ClientDesk | Customer support ticketing portal | [clientdesk-pi.vercel.app](https://clientdesk-pi.vercel.app) |
| InsightBoard | Financial / operational BI dashboard | [insightboard-ten.vercel.app](https://insightboard-ten.vercel.app) |
| LeadFlow CRM | Sales pipeline CRM for SMBs | [leadflow-crm-lime.vercel.app](https://leadflow-crm-lime.vercel.app) |

## Local preview

```bash
# Any static server. With Python:
python3 -m http.server 4000
# Then open http://localhost:4000
```

No npm install, no build, no config.
